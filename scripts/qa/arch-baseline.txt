# messageKeys 由 remember(messages) 算、key lambda 在测量阶段才调用，工具卡插入的那一帧

# 2026-11-12 上调（RealAgentLoop +4）：A-2 修「回合预算只挡步边界」。
# 只加三样：executeBatch 一个参数、一次实参（loopStart + turnBudgetMs）、
