# AgentKit 使用说明

> 写给第一次用的人。按顺序做，五分鐘能用起来。

---

## 一、装好之后，先配模型

AgentKit 自己不会思考，它要接一个大模型（相当于给 App 装一个"脑子"）。没配之前，发什么都得不到回答。

**入口：** 左上角 ☰ → 模型配置

### 三个步骤

**1. 选供应商**

页面上方有一排配置名（`新建配置` `＋`）。点 `＋` 新建一个，然后在下面「模型接入 → 供应商」里挑一家：

| 你想要 | 选哪个 | 说明 |
|---|---|---|
| 便宜、中文好 | DeepSeek | 按量计费，几块钱能用很久 |
| 长文本、稳定 | Kimi / 通义 / 智谱 / 豆包 | 国内直连，不用梯子 |
| 效果最好 | Claude / Gemini | 需要对应的 Key，部分需外网 |
| 自己有服务器 | OpenAI 兼容 | 填你自己的地址，Ollama / LM Studio / one-api 都选这个 |

**2. 填 API Key**

到供应商的控制台（比如 DeepSeek 的 `platform.deepseek.com`）生成一把 Key，复制粘贴进「API Key」输入框。

> Key 只存在你手机本地，不会上传到任何地方。

**3. 点「测试连接」**

显示成功就配好了。回到对话页，直接在输入框输入你要它做的事。

### 想让它看图？

选支持视觉的模型（GPT-4o、Claude、Gemini、GLM-4V 这类）。纯文本模型发图片它也看不懂。

---

## 二、能做什么

配好模型后，它就是普通的 AI 对话——但比网页版多了两件别人没有的事：

**① 它能看见你的屏幕**

说「看看现在屏幕上是什么」，它会截一张图自己看。

**② 它能替你点**

说「打开设置，把 WLAN 关掉」「在微信里找到张三，发一句我到了」，它会真的去点。

> 这两件事需要先开**无障碍服务**：☰ → 权限中心 → 无障碍 → 打开 AgentKit。
> 不开也能用，只是退化成普通对话。

## 三、日常用法

### 说话不用讲格式

直接说人话：

```
把刚才那段代码改成 Kotlin
```

```
帮我看看这个报错是什么意思
```

```
明天下午三点提醒我开会
```

### 长任务会先给计划

默认「先计划后执行」：三步以上的事，它会先列一个计划让你确认，你点了才动手。想让它直接干，去设置里切成「自动执行」。

### 处理文件

- 点输入框左边的 `＋` 可以发图片、发文件
- 说「读一下这个文件」它会自己打开
- 它有一个工作区目录，可以读写文件、跑命令
- 要读**工作区以外**的文件（相册、下载目录、别的应用的数据），第一次会弹一次确认，
  告诉你它要读哪个目录；同一个目录再读就不再问

### 隐私数据

剪贴板和通知里常有密码、验证码、聊天内容，所以这两样**读之前一定会问你**：

- 读剪贴板 → 弹「读取剪贴板」；同一个会话里再读不再问
- 读通知 → 弹「读取通知」；同理
- **写剪贴板不问**（它只是把一段文字放到剪贴板，没有把你的东西送出去）
- 两个授权互相独立：同意读剪贴板，不等于同意读通知

**读屏也算一类**：截图（`ui_screenshot`）和「不传 path 的 OCR 文字识别」看的是同一块屏幕，
所以共用一次授权——同意过其中一个，另一个不会再问。OCR 只是把画面变成文字返回，
但它拿到的东西和截图一样，因此不会因为「只是识别文字」就免掉这一问。

**它「自己看到」的东西里不含通知正文。** 对话里会附一段「当前设备上下文」，告诉你
手机上正在发生什么；那段里只有「哪个应用推了几条、多久之前」，比如「微信 ×2（3 分钟前）」。
标题和正文一律不在里面——那些得靠它去读，而读就要先问你。所以别奇怪它为什么说
「微信有两条新消息」却说不出内容：它确实没看到。

**日志里也不写你的内容。** 排查问题用的运行日志只记「调了哪个工具、成功没有、返回多少字节」，
不记工具看到的具体内容；连你发的消息也只记「多少字」。点「导出诊断包」带走的就是这份日志——
所以上面这些边界不是只在界面上生效，它跟着日志一起走。

### 定时任务

说「每天早上八点帮我总结一次科技新闻」，它会建一个定时任务。在抽屉里能找到。

## 四、扩展：技能与插件

**技能**是给 Agent 的"说明书"——装上之后，它就知道某种任务该怎么做。

**入口：** ☰ → 技能中心

- **内置技能**：装好就有（天气、网页抓取、终端等）
- **导入技能**：点「导入」，选一个 zip 包
- **插件市场**：技能中心 → 插件市场 → 填索引地址，浏览并一键安装

市场索引地址（可填这个试用）：

```
https://kdkdmwnwdkd.github.io/Polaris/market-demo/index.json
```

> 导入的技能默认降权：不能执行脚本，只能用低危工具。要让它跑脚本，得在技能中心手动授权。

> **联网**：技能脚本只能访问它在 `skill.json` 里用 `net_hosts` 声明过的域名
> （例如 `"net_hosts": ["api.example.com", "*.openweathermap.org"]`）。
> 没声明就一律拒绝——脚本跑在后台线程里，弹不出确认框，所以网络权限只能提前声明。
> 主对话里模型自己发起的网络请求不受这条限制，它会每次都问你。
>
> **这些域名不用你去翻 zip**：市场安装时会先下载、校验，然后把包里声明的域名列出来，
> 你点「安装」才真正落盘；装好之后技能卡上也常驻一行「可联网：……」，授权脚本时的
> 确认框里同样会逐条列出。写错的声明会被标红（裸 `*`、带 `https://`、带路径、
> `api.*.com`、带端口都算写错）——那些条目运行时一律不命中，不标出来就只能怪网络。

> **包有大小限制**：单个技能 zip 上限 8MB（和市场安装同一个数）。超了会直接报
> 「超过 8MB 上限」，不会先下完再拒——所以给个几百兆的地址也不会把 App 拖死。

## 五、数据与备份

**入口：** ☰ → 设置 → 备份与恢复

- 导出会生成一个 ZIP，含全部会话、记忆、模型配置
- **不含 API Key**：导出时会把 Key 与鉴权头清空（老版本导出的包如果里面有，导入时
  也以本机已填的为准，不会被覆盖回旧值）——所以这个包可以放心放网盘
- GitHub PAT 不会写入备份（恢复时沿用本机已存的）

换手机就靠这个文件。

## 六、常见问题

**Q：一直转圈不出字？**
先看模型是不是配好了（对话页顶部有当前模型名）。再看 Key 有没有余额。用「测试连接」单独测一次最快。

**Q：连不上自己的 Ollama / 局域网服务？**
地址要填完整：`http://192.168.1.10:11434/v1`（注意结尾的 `/v1`）。手机和电脑要在同一个 Wi-Fi。API Key 那一栏随便填一个非空的值（比如 `ollama`），不能留空。

**Q：它说没有权限？**
- 操作屏幕 → 需要无障碍服务
- 读通知 → 需要通知使用权
- 装应用 → 需要「安装未知应用」权限

都在 ☰ → 权限中心 里，会显示哪些还没开。

**Q：点了没反应 / 卡住？**
对话页有停止按钮。终端命令有自己的超时（默认 30 秒），超时会自动中断并提示。

**Q：耗电吗？**
纯对话不额外耗电。跑本地模型（llama.cpp）会明显发热，那是手机在跑推理，正常。

---

## 七、它不会做的事

- 不会把你的 API Key 传到除你配置的模型服务之外的地方
- 不会在你没授权的情况下操作屏幕
- 不会自动删除你的文件（破坏性操作会先问你）
