# 语音：删掉系统识别，四套模型改成可下可删（2026-11-16）

## 一句话

安装包从 **361MB 降到约 30MB**；语音识别不再依赖系统引擎；四套模型（识别 2 + 音色 2）
都在应用内下载、随时删除。用户原话：「那个没用，删了」「全部搞成能下能删的」。

## 改了什么

### 1. 系统语音识别整条删除

真机证据（2026-11-15 日志）：

- Google 的识别服务：`checkRecognitionSupport` 直接超时（国内不可达）；
- 高通引擎：明确返回「不支持当前语言」，且没有中文离线包。

两个引擎都出不了中文，而「语音识别」这一项在部分 ROM 的设置里根本不存在
（2026-11-14 截图：默认应用里只有「文字转语音输出」）。也就是说，之前那一整组
「引擎清单 + 换引擎 + 去系统设置」全是死路。

删除清单：

| 删除 | 原来负责什么 |
|---|---|
| `audio/SpeechProbe.kt` | 枚举系统识别服务、逐引擎问语言支持 |
| `core/voice/SpeechCapabilityPolicy.kt` | 「能不能识别」判定表 + 错误码翻译 |
| `core/voice/RecognitionEngine.kt` | 引擎能力模型 / 挑选 / 命名 |
| `audio/VoiceEngineStore.kt` | 用户钉住的识别引擎 |
| `ui/VoiceInputLogic.kt` | 系统识别页 Intent 构造 |
| `pet/PetVoice.kt` 里的 `SpeechRecognizer` 分支 | 桌宠的系统识别路径 |
| `ui/ChatScreen.kt` 里的 `voiceLauncher` | 聊天页弹系统识别页 |

保留并强化：`audio/asr/`（自带离线识别）、`LocalSpeechInput`（自己录音 + 仲裁）、
`PetVoice`（只走本地，没模型就明确拒绝并给下载入口）。

### 2. 四套模型统一成「可下可删」

新增 `model/` 包：

- `ModelSpec`：四个模型的唯一清单（zip 名 / 落盘目录 / 必需文件 / 体积）；
- `ModelDownloader`：一个 zip 一次下载，多源（`GitHubMirror`）→ 校验 sha256 → 解压；
- `ModelZip`：解压到 `.new` → 核对必需文件 → 换名，防 zip slip、防解压炸弹。

| 模型 | 体积 | 落盘 |
|---|---|---|
| 快速识别（流式 zipformer） | 24MB | `filesDir/asr/zh-streaming` |
| 更准识别（paraformer） | 74MB | `filesDir/asr/zh-paraformer` |
| 内置音色（matcha + vocos） | 139MB | `filesDir/tts/matcha` |
| 声音克隆（ZipVoice） | 196MB | `filesDir/tts/zipvoice` |

界面：识别页只管两套识别；音色页新增「音色模型（可下可删）」组。
每行都是同一个交互：未下载 → 点击下载（显示百分比）；已下载 → 点击删除。

### 3. CI：模型不再进 APK

- 构建只拉原生运行时（`.so`），`POLARIS_MODELS=0` 跳过 335MB 权重；
- 新增 `Publish voice model assets`：把四套权重打成 zip + 一份 `model-manifest.txt`
  （`资产名 字节 sha256`）传到 `latest` Release，四件齐全才跳过（幂等）；
- 包体守卫：`assets/tts` 非空 → 构建直接失败（防「悄悄涨回 361MB」）。

## 升级兼容

746 及更早的用户是按**逐文件**下载识别模型的，落盘路径与现在完全相同。
新下载器按「必需文件是否齐全」判定，因此升级后**不需要重下已装的模型**。
音色模型此前随包，升级后会显示「未下载」——需要重新下一份（这正是这次改动的目的：
让不用的人不付这份空间）。
