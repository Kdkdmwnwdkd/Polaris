# 桌宠形象：从「一个盒子」换成重绘位图（2026-11-18）

## 起因

一期落地的形象是 `PetPanel.kt` 里 Canvas 现场画的圆角方块，作用是先证明
「窗口能活、能拖、能对话」，不是定稿。真机上一眼就能看出它是占位：

> 桌宠完，现在是没有形象吧，就一个盒子而已

## 为什么是「重绘」而不是「直接用」

参考形象来自公开的二创（蓝发 + 呆毛 + 鲸鱼鳍耳 + 大鲸尾 + 女仆装 + 围裙小鲸鱼），
网上流传的图很多。但**公开可看不等于可再发行**：这个 APK 挂在 GitHub Release 上
对所有人开放下载，把别人的画打进安装包属于复制发行。

所以走的是「照参考图重画一版」：角色设定（发型、耳朵、尾巴、服装）本身不受著作权保护，
受保护的是**那一张具体的画**。重绘出来的是新画，可以内置、可以改、没有后顾之忧。

## 色值不靠眼睛估

第一版画成了冰蓝（`#a8c0d8`），跟参考图（`#484860` / `#6c6c90`，平均 `#72728e`）差了
0.46 vs 0.78 的亮度——不是「色调偏差」，是根本没对上。第二轮改成从参考图**采样取色**
再写进 prompt，并逐张回采验证：

| | 归一化主色 | 平均亮度 |
|---|---|---|
| 参考图 · 头发 | `#484860` `#6c6c90` | 0.45 |
| 最终版 · 头发 | `#485478` | 0.36 |
| 最终版 · 尾巴 | `#3c5484` | 0.31 |

深蓝偏紫，不是冰蓝也不是灰。这条写在这里是因为**它是最容易返工的一处**：
颜色错了，后面所有状态帧都要重做。

## 资源规格

| 文件 | 尺寸 | 体积 | 用途 |
|---|---|---|---|
| `res/drawable-nodpi/pet_avatar_open.webp` | 384×384 | 28,068 B | 常态（睁眼） |
| `res/drawable-nodpi/pet_avatar_blink.webp` | 384×384 | 26,986 B | 眨眼帧（闭眼） |

三件事是刻意的：

1. **`drawable-nodpi` 不是 `drawable`**。放 `drawable/` 会被按屏幕密度缩放，
   同一张图在 2x / 3x 上得到不同的有效分辨率，眨眼切换时边缘会闪。
2. **两张共用同一个裁剪框**。第二张是用第一张当底图重绘的（`image1` 输入，
   `input_fidelity: high`），两张的 `getbbox()` 完全一致；裁剪时再取并集，
   所以闭合时不位移、不抖。
3. **384px 而不是 1024px**。96dp 在 3x 屏上是 288px，384 留了余量；
   WebP q=88 后每张 28KB，两张合计 55KB，APK 几乎不涨。

## 代码

`PetBody()` 从「画方块」改成「画图 + 叠光晕」，保留的动画三个：呼吸（上下浮动）、
眨眼（两张图交叉淡化）、听声时向外扩散的圈。

- 光晕画在图**之前**：听声时最亮，思考次之，空闲只留 0.08。没有它，深色壁纸上
  一张深蓝头发的人物会糊进背景。
- 落地阴影同理，画在图之前，被脚和尾巴压住一半才自然。
- `thinking` 没有嘴型可动了，改成呼吸快一倍（900ms vs 2000ms）——
  收起态下用户看不到任何文字，这是唯一能表达「它在跑」的东西。
- 窗口 `PET_SIZE_DP` 84 → 96。方块的身体只占窗口 62%，换图后人物占满 90%，
  同样是 84dp 会显得小一号；96dp 下人物约 90dp，五官在小尺寸上还分得清。
  遮挡面积 +30%，这是这个尺寸的上限——再大就该做「收起时只露半个身子」，
  而不是继续涨窗口。

## 守卫（`run-desktop-pet-verification.sh` `[M]` 段，5 条）

| 编号 | 守什么 | 为什么会坏 |
|---|---|---|
| M1 | 两张资源都在 `drawable-nodpi` | 方块绘制已删，资源丢了就是空白窗口 |
| M2 | 该目录只放 webp | 有人塞回 png 会破坏上面的密度假设 |
| M3 | 单张 < 60KB | 防止哪天换成 1024px 大图，APK 悄悄涨几百 KB |
| M4 | 两张图共用同一组 `dstSize`/`dstOffset` | 目标矩形不一致 = 眨眼时人物抽一下 |
| M5 | 走 `drawImage`，没有残留 `drawRoundRect` | 只改一半会留下两套实现，肉眼看不出来 |

## 已知边界

- **没有张嘴说话**：静态图做嘴型要逐帧，成本不成比例；朗读时靠光晕与呼吸表达。
- **换形象只需换这两张图**：`PetBody()` 里没有写死任何角色特征，尺寸与对齐都在
  裁剪阶段定好。真要换角色，重新导两张同构图的 384² webp 覆盖即可。
- 生成图用的是「照参考重绘」，**不保证与原作相似度**——这是有意的。
