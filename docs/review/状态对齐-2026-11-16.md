## 二、这三天真正发生了什么（按主题，不是按提交）

### 1. 语音：从"调系统引擎"改成"自带引擎 + 模型可下可删"

这是最大的一处，**旧简报 §3.6 整段失效**。

- **删掉的**：`SpeechProbe` / `SpeechCapabilityPolicy` / `RecognitionEngine` / `VoiceEngineStore` / `VoiceInputLogic`，以及 `PetVoice` 与 `ChatScreen` 里的 `SpeechRecognizer` 分支
- **理由（真机日志）**：Google 识别服务在国内超时；高通引擎明确回"不支持中文"且无中文离线包；部分 ROM 的设置里根本没有"语音识别"这一项 → 原来的"引擎清单 + 换引擎 + 去系统设置"三条路全是死路
- **换上的**：`app/audio/asr/`（`OfflineAsrEngine` / `StreamingAsr` / `AsrRouter` / `LocalSpeechInput`，sherpa-onnx）
  - 两套识别：快速流式 24MB、更准整段 74MB
- **TTS**：本地 matcha 139MB 内置音色；ZipVoice 196MB 零样本克隆（录一句话用自己的声音）；`EdgeTts` + `SecMsGec` 接通在线 6 个神经音色，令牌本地算、不用填 key
- **统一模型层**：`core/model/{ModelSpec, ModelDownloader, ModelZip}` —— 四套模型一个清单、一次下载、sha256 校验、`.new` 目录换名防 zip slip

### 2. 包体：从"全都塞进 APK"改成"壳 + 按需下载"

- 语音模型不再进 APK：`POLARIS_MODELS=0` 跳过 335MB 权重，CI 另发 `Publish voice model assets`（zip + `model-manifest.txt`，幂等）
- 加了**包体守卫**：`assets/tts` 非空 → 构建直接失败（防悄悄涨回 361MB）
- 容器 rootfs 与 Shizuku 安装包也搬出包（`scripts/assets/containers/`、`.gitignore:26`）
- 平台约束写清楚了：引擎 `.so` **不能**按需下载（`classloader-namespace` 限制），所以"壳"有下限

### 3. 其他
- 自动续跑（11-14）：`AutoResumePolicy` + 熔断 2 次/24h，已被 39 条行为断言钉住
- 桌宠三期（磁贴 + 通知按钮）在模拟器上把 P11–P13 的大部分判据跑掉了
