## 关键取舍

1. **没有把 shell 改成"每次都问"**。那会让 `npm install` 这类正常命令也每次弹窗，
   用户很快就会养成闭眼点允许的肌肉记忆——R-08 修这个问题的初衷会反弹回去。
   现在保留"可记忆"，但把可记忆范围从「除黑名单外的一切」缩成「只读命令 + 构建/查询白名单」。
2. **网络按域名记忆**，不是每次必问。正常查资料只在首次访问某域名时问一次；
   把数据发去一个新域名必须过一次人——这正好卡住外泄链的关键一步（攻击者域名是新域）。
3. **提权命令不看命令内容**。`ls` 换了 uid 2000 能看的东西完全不同，权限才是风险变量。
4. **MCP 一律不可记忆**。外部服务器提供的工具，用户没法评估"这一类操作"的边界。

纯函数部分（`ShellCommandRules` / `ApprovalScope` / `ApprovalGrouping` / `ToolCatalog`）
已用 Kotlin 1.9.24 编译器真实编译并执行断言，**73 条全过**，覆盖：

- 仓库既有 `R08Verification` 的 A/B/C 三组判定（分类、授权键、不变量），逐条复跑；
- 新增绕过用例：`busybox` / `env` / `nohup` / `$()` / 重定向 / `cp` / `python -c` / `sed -i` / `tree -o`；

## 建议补的回归断言（本次未加，避免动到 harness 计数与门禁）

在 `scripts/qa/R08Verification.kt` 的 `testGrant()` 里追加：

```kotlin
check("B8 包装命令不可记忆") {
    listOf(
        "busybox rm -rf /sdcard/DCIM", "\$(rm -rf /sdcard/DCIM)",
        "cp /dev/null /sdcard/a.txt", "echo x > /sdcard/a.txt",
        "python3 -c 'x'", "nohup rm -rf /x &"
    ).forEach { expect(!shellGrant(it).memorizable) { "可被记住：$it" } }
}
check("B9 提权 shell 不可记忆") {
    expect(!shellGrant("ls -la", "shizuku").memorizable)
}
check("B10 MCP 工具不可记忆") {
    expect(!ApprovalScope.of("mcp_files_read", JsonObject(emptyMap())).memorizable)
}
check("B11 网络按域名分键") {
    val a = ApprovalScope.of("http_request", argsOf("url" to "https://api.deepseek.com/x"))
    val b = ApprovalScope.of("http_request", argsOf("url" to "https://evil.example/c"))
    expect(a.key != b.key) { "不同域名共用了同一个键" }
}
```
